# 微型图书借阅系统
## 1.系统目标
	    设计并实现一个功能完善、操作便捷的图书借阅管理系统，支持图书和读者的基础信息管理、图书借
	阅与归还流程处理、信息查询以及数据持久化存储，满足小型图书馆或图书管理场景的日常运营需求，
	确保图书资源的有序管理和高校利用
## 2.核心业务范围
	    系统围绕“图书”和“读者”两⼤核⼼实体展开，覆盖信息录⼊、状态更新、查询统计、数据维护四
	⼤业务模块，具体包括图书/读者的添加与删除、图书借阅与归还操作、多维度信息查询、数据的加
	载与保存，同时需处理业务约数（如借阅数量限制、借出状态限制，其中上线值为MAX，可自行调节）
## 3.系统约束
	    数量容量限制：最多支持存储50本图书和50位读者，超出容量时禁⽌新增数据并给出提示。
        ◦ 借阅规则约束：每位读者最多可借阅3本图书，已借满时⽆法继续借阅；图书处于借出状态时⽆法重复借
	阅，也⽆法删除。
        ◦ 数据唯⼀性约束：图书ISBN和读者ID为唯⼀标识，不允许重复添加。
        ◦ 数据持久化约束：系统启动时自动加载历史数据，操作过程中检测到数据修改时，退出系统前需提示用户
	是否保存更新后的数据。
## 4.交互要求
	    系统采用控制台交互⽅式，提供清晰的功能菜单供用户选择操作，所有输⼊输出需具备明确的提示信息
	，操作结果（成功/失败）需及时反馈给用户，错误操作时需给出具体的错误原因（如“ISBN重复”“读
	者不存在”等）
# 功能介绍
# 一、功能数量以及种类:
	功能共有13个分别为:
	        添加书籍,删除书籍,显示书籍,书籍借阅,书籍归还,书籍查询,保存书籍,添加读者,删除读者,显示读者,
	      查询读者,保存读者,退出系统。
# 二、功能详细介绍
##     添加书籍（addbook）:
			先会判断书籍数量是否达到最高值（MAX），如果达到会终止功能并提示"图书库已满（最多50本）已终止添
	      加！"如果没有达到上线会提示输入图书的ISBN以及书籍名称（如果有相同ISBN同样终止功能）输入后及添加
	      完成。
##     删除书籍（deletebook）:
			先输入图书的ISBN，如果未发现有相同的ISBN将提示"未有ISBN为（输入的ISBN）的书籍,已终止操作!"，
	      如果发现有相同的ISBN将会删除并提示"已成功删除此书籍!"。
##     显示书籍（showbook）：
			此功能会显示所存在的所有书籍，信息格式统⼀为：ISBN：XXX，书名：XXX，状态：XXX，借阅者：XXX。
##     书籍借阅（borrowbook）:
			需先输入读者ID以及借阅书籍的ISBN，如判断时发现未有读者或ISBN将终止操作，也会判断读者的借书上线 
	      如达到上线也同样会终止操作（默认上线为3，可修改），最后判断书籍是否借出，如未借出则输出"借阅成功"
	      否者失败。
##     书籍归还（returnbook）:
			需先输入要归还书籍的ISBN，输入后会判断书籍是否被借阅或存在若没有将退出程序并输出“图书未借出或不
		  存在！”，根据readid可以找到读者的ID，找到后更新读者借阅数量和图书状态最后输入“归还成功！”。
##     书籍查询（findbook）:
			模糊的查找读者，大体就是输入关键词，后根据关键词判断是否有书名类似或包含字符的书籍，若找到输出“
		  该图书的ISBN、书名、状态（“已借出”或“可借”），若未找到该图书将输出“未找到匹配书籍”并退出。
##     保存书籍（savebook）:
			将当前系统内存中的所有图书数据写入books.txt文件，实现数据持久化。首先会打开books.txt后面会将
		  ISBN 书名 借出状态标识 借阅者ID的格式逐⾏写⼊数据，这里借出判断和以往不同借出状态标识规则：“已
		  借出”对应写⼊“1”，“可借”对应写⼊“0”，完成后将输入图书数据以保存。
##     添加读者（addreader）:
			先会判断读者数量是否达到上限（上线为MAX，可调节），若超出范围则停止操作，其次就是输入读者ID
		  如果判断ID有重复的话，则退出该操作。创建新读者后将借阅书籍数量调为0并输出“添加成功！”，并且将
		  bool的change改为true（判断数据更改），这样可以在退出时做出保存判断。
##     删除读者（deletereader）:
			输入想要删除的读者，后面去调用findreader函数查找是否有此读者，若没有将终止操作。判断是否有读者
		  后会去判读者借阅书籍的值，若有未归还书籍输出“读者有未还图书，无法删除！”并终⽌操作。若通过所有检测
		  将删除读者并改变change为true。
##     显示读者（showreader）:
			首先会判断读者的数量是否为0，若是的话将输出“当前没有读者，请前往添加！”并停止该操作。若存在读者
		  将会输出“读者列表：”，每位读者需展⽰的信息包括：ID、姓名、已借图书数量（格式为“X/3本”，X为当前已借
		  数量） 信息格式统⼀为：“ID：XXX，姓名：XXX，已借：XXX/3本”。
##     查询读者（findreader）:
			输入读者ID，若未找到读者ID相同的将输出“未有此读者，请前往添加！”并终止操作。后提⽰输出标题“读者X
		  XX当前借阅的图书：”（XXX为读者姓名 遍历图书数组，查找借阅者ID与输⼊读者ID⼀致的图书，若找到则输出该
		  图书的ISBN和书名，否则，输出“该读者未借阅任何图书！”）。
##     保存读者（savereader）:
			将当前系统内存中的所有读者数据写⼊readers.txt⽂件，实现数据持久化。打开（若不存在则创建）readers.txt 
		  ⽂件，以覆盖写⼊的⽅式操作。遍历读者数组，按“读者ID姓名已借图书数量”的格式逐⾏写⼊数据。写⼊完成后关闭⽂件
		  ，输出“读者数据已保存！”。
##     退出系统（没有调用函数，而是在case中直接编写）:
			当⽤⼾选择退出选项时，检查数据是否被修改过。若被修改过，提⽰⽤⼾“检测到未保存的数据（当时定义的bool变
			量“change”如果为false直接输出“再见”，若为true将经行检测），是否保存？(y/n):”，等待⽤⼾输⼊（这里如果
			保存输入y或Y，不保存输入任意字母）。保存或者直接退出后输出“再⻅！”，终⽌程序运⾏。
