# 微型图书借阅系统
## 1.系统目标
	    设计并实现一个功能完善、操作便捷的图书借阅管理系统，支持图书和读者的基础信息管理、图书借
	阅与归还流程处理、信息查询以及数据持久化存储，满足小型图书馆或图书管理场景的日常运营需求，
	确保图书资源的有序管理和高校利用
## 2.核心业务范围
	    系统围绕“图书”和“读者”两⼤核⼼实体展开，覆盖信息录⼊、状态更新、查询统计、数据维护四
	⼤业务模块，具体包括图书/读者的添加与删除、图书借阅与归还操作、多维度信息查询、数据的加
	载与保存，同时需处理业务约数（如借阅数量限制、借出状态限制，其中上线值为MAX，可自行调节）
## 3.系统约束
	    数量容量限制：最多支持存储50本图书和50位读者，超出容量时禁⽌新增数据并给出提示。
        ◦ 借阅规则约束：每位读者最多可借阅3本图书，已借满时⽆法继续借阅；图书处于借出状态时⽆法重复借
	阅，也⽆法删除。
        ◦ 数据唯⼀性约束：图书ISBN和读者ID为唯⼀标识，不允许重复添加。
        ◦ 数据持久化约束：系统启动时自动加载历史数据，操作过程中检测到数据修改时，退出系统前需提示用户
	是否保存更新后的数据。
## 4.交互要求
	    系统采用控制台交互⽅式，提供清晰的功能菜单供用户选择操作，所有输⼊输出需具备明确的提示信息
	，操作结果（成功/失败）需及时反馈给用户，错误操作时需给出具体的错误原因（如“ISBN重复”“读
	者不存在”等）
# 功能介绍
# 一、功能数量以及种类:
	功能共有13个分别为:
	    	添加书籍,删除书籍,显示书籍,书籍借阅,书籍归还,书籍查询,保存书籍,添加读者,删除读者,显示读者,
	   查询读者,保存读者,退出系统。
# 二、功能详细介绍
	## 添加书籍（addbook）:
		先会判断书籍数量是否达到最高值（MAX），如果达到会终止功能并提示"图书库已满（最多50本）已终止添
	       加！"如果没有达到上线会提示输入图书的ISBN以及书籍名称（如果有相同ISBN同样终止功能）输入后及添加
	       完成。
	## 删除书籍（deletebook）:
		先输入图书的ISBN，如果未发现有相同的ISBN将提示"未有ISBN为（输入的ISBN）的书籍,已终止操作!"，
	       如果发现有相同的ISBN将会删除并提示"已成功删除此书籍!"。
	## 显示书籍（showbook）：
		此功能会显示所存在的所有书籍，信息格式统⼀为：ISBN：XXX，书名：XXX，状态：XXX，借阅者：XXX。
	## 书籍借阅（borrowbook）:
		需先输入读者ID以及借阅书籍的ISBN，如判断时发现未有读者或ISBN将终止操作，也会判断读者的借书上线 
	       如达到上线也同样会终止操作（默认上线为3，可修改），最后判断书籍是否借出，如未借出则输出"借阅成功"
	       否者失败。
